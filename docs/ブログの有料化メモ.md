# ブログの有料化メモ（2026-10-22 作成）

## 現状
- 記事JSONに `access`（"free" / "members"）と `paid_from`（日付）を持たせている
- いまはすべて `access: "free"` で、本文は全文公開
- `access: "members"` にすると、`teaser`（導入文）だけ見せて「続きは会員向け」を出す設計

## リポジトリが public なので、有料の本文をどこに置くか

### A案：Cloudflare Pages Functions + KV
- 記事JSONの `body` は空にして、KV に本文を保存する
- Pages Functions（サーバーサイド）で会員認証 → KV から本文を返す
- 長所：Cloudflare のインフラだけで完結、Pages の無料枠が大きい
- 短所：KV の書き込みにダッシュボードか API が必要

### B案：Cloudflare R2 + 署名付きURL
- R2 バケットに本文HTMLを置く
- Pages Functions で認証 → 署名付きURLを返す → クライアントで表示
- 長所：画像・ファイルも有料にできる、容量の心配が少ない
- 短所：クライアント側で取得するため、ソースを見れば URL がわかる（期限付きで緩和できる）

### C案：会員制にしない
- 全記事を無料公開のまま運用する
- ブログは集客・ファンづくりに使い、収益は商品の販売で得る
- 長所：いちばんシンプル、SEOにも有利
- 短所：コンテンツ自体での収益化はできない

## 龍さんへの確認
- いまは全記事 `access: "free"` にしている
- 将来 members にしたくなったら、A案・B案のどちらかを実装する
- JSON の形は変えなくてよい（`access` を書き換えるだけ）
