この一着の話

川越の古民家で古着屋をしている、小判鮫です。甲と履き口に、ナチュラルカラーのパイソン革を使っています。メキシコ製、Adams Bootsのヴィンテージ・ウエスタンブーツです。

意匠

パイソン革（ヘビ革）をブラウンのレザーと組み合わせ、ウイングチップ状のオーバーレイと羽のように広がるステッチを重ねています。つま先はすっと伸びたポインテッドトゥです。鱗の陰影と、履き込まれたレザーの艶が並びます。

状態

かかと・つま先のスレ、レザーのシワ、全体的な使用感があります。パイソン部分に目立つ欠けや大きな損傷はありません。

合わせ方

デニムをロールアップして甲のパイソンを覗かせるのはもちろん、スラックスやワンピースの外しにも使えます。男女問わず履けます。
