1990年代頃 Champion USA製の半袖ラグランスウェット

小判鮫

今日は Champion の半袖スウェットについて解説します。

1990年代頃のUSA製で、ラグランスリーブの半袖スウェットなんです。今回は、タグから分かることを中心に紹介します。

首のタグを読む

首の内側には、青地のタグ。Champion のロゴの下に、サイズの「LARGE」、そして「SINCE 1919」と入ってます。1919年は、チャンピオンが設立された年です。

もう1枚のタグには「IT TAKES A LITTLE MORE TO MAKE A CHAMPION」の文字と「U.S.A.」。タグを見ると、アメリカで作られた1枚だと分かります。年代を1990年代頃としているのは、このタグの表記からです。

チャンピオンの始まり

始まりは1919年、ニューヨーク州のロチェスター。フェインブルーム兄弟がニット工場「Knickerbocker Knitting Mills」を立ち上げ、大学のスポーツチームのウェアを作ったのが最初です。1930年代に「Champion Knitting Mills」という名前になります。

よく知られている「リバースウィーブ」は、生地を横向きに使って、洗ったときの縦の縮みを抑える作り。1938年と1952年に特許が取られてます。1989〜1997年には、NBAの公式ウェアも手がけてるんですね。（出典：Textile World「Champion Athleticwear Celebrates 100 Years」2019年）

細かいところ

胸には小さな C のロゴ、袖には C のワッペン。古着屋のあいだでは、胸の C ロゴを「目」と呼び、ロゴがあるものを「目付き」、ないものを「目無し」と言います。この1枚は目付きですね。

首元のV字の部分は「Vガゼット」と呼ばれるディテールです。汗止めや補強、生地の縮みを防ぐための作りとされています。（出典：2nd STREET「チャンピオンのリバースウィーブとは」）

脇の縫い目には、白い脇タグが付いてます。文字はかすれて読めませんが、全体の状態はいいですね。

着方の一言

身幅64cmのゆったりめ。半袖なので、長袖のTシャツを下に重ねても袖がもたつきにくいですよ。
